# Giới thiệu
Đây là project học tập được xây dựng trong quá trình học **Kỹ nghệ phần mềm / Công nghệ thông tin**.  
Mục tiêu của project là rèn luyện **tư duy lập trình hướng đối tượng (OOP)**, cách tổ chức mã nguồn và áp dụng kiến thức Java vào bài toán thực tế cơ bản.
Project phù hợp với sinh viên / fresher IT muốn làm quen với quy trình phát triển phần mềm.

# Công nghệ sử dụng
- **Ngôn ngữ:** Java  
- **Mô hình:** Lập trình hướng đối tượng (OOP)  
- **IDE:** NetBeans / IntelliJ IDEA  
- **Công cụ quản lý mã nguồn:** Git, GitHub  

# Chức năng chính
- Xây dựng chương trình Java cơ bản
- Áp dụng các khái niệm:
  - Class & Object  
  - Encapsulation  
  - Inheritance  
  - Polymorphism  
- Tổ chức code rõ ràng, dễ mở rộng
- Thực hành tư duy giải quyết vấn đề bằng lập trình
